# Sessões

Uma linha por sessão de trabalho (30 minutos ou mais, em qualquer horário). Sessão menor não entra e não conta no orçamento. Regras em [04-roteiro](04-roteiro.md). Para preencher pelos commits: `/fechar-sessao` no Claude Code.

Formato: `data · fase · usadas/orçamento · código ou design · o que fez`

Fase estoura quando passa de 1,5× o orçamento: corta escopo, nunca troca de stack.
