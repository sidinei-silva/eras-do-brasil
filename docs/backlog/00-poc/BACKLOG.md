# Backlog — PoC de Eras do Brasil

> Cada fatia entrega algo que o jogador **vê ou faz**. As Fatias 1–3 são
> infraestrutura (conta, login, personagem — só backend, enquanto o Godot
> ainda está em estudo). Da Fatia 4 em diante, cada fatia mapeia um dos
> passos do tutorial (compêndio, Parte XI). O detalhe de cada fatia mora em
> [fatias/](fatias/).
>
> Quando uma fatia estiver decidida (sem "A decidir" pendente): os `- [ ]`
> dela viram issues num Milestone do GitHub com o nome da fatia.

## Escopo da PoC

A PoC será um espelho do tutorial do Albion Online de maneira portada para idle.
Ver o arquivo [Visão do Dev](./VISAO_DEV.md) para detalhes do tutorial do albion e como será dividido.
