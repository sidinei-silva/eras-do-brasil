# Fatia 1 — Criação de conta (Backend)

**Status:** concluída

## Servidor

- [x] Preparação inicial do server: configuração de HTTP, banco de dados

## Regras

- O jogador só pode criar uma conta por email
- O email precisa ser válido
- O jogador precisa colocar a senha e a confirmação da senha
- A senha precisa ter no mínimo 8 caracteres
- A senha e a confirmação precisam ser iguais
