# Noites

Uma linha por noite trabalhada (30 minutos ou mais). Noite sem trabalho não gera linha e não conta no orçamento. Regras em [04-roteiro](04-roteiro.md).

Formato: `data · fase · usadas/orçamento · código ou design · o que fez`

Fase estoura quando passa de 1,5× o orçamento: corta escopo, nunca troca de stack.
